fexdroid: https://github.com/cobrabm12/fexdroid (MIT License, below). The app's
Java package name comes from it; the display and input bridge libraries of earlier
releases (libfxdisplay, libfxio) are no longer included.

GPU drivers: the app contains none. Turnip for Android builds the player installs
or downloads from this project's GitHub releases are Mesa (MIT,
https://gitlab.freedesktop.org/mesa/mesa; the Adreno 8xx variant from
https://github.com/whitebelyash/mesa-unified, turnip/gen8, MIT), with this
project's patches (tools/android/mesa-patches in the source).

Menu icons: Material Design icons (Apache-2.0, Google).

Commons IO 2.15.1, Apache Commons Codec 1.16.1 and Apache Commons Lang 3 3.20.0 (all
Apache-2.0), with XZ for Java 1.12 (0BSD, Lasse Collin). Their notices:
